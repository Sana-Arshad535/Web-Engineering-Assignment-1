# ChowChowCrochet 🧶

## 📌 Project Overview

ChowChowCrochet is a handmade crochet accessories website developed as part of my **Web Engineering Assignment 1**. It showcases different crochet products, allows users to explore product categories, and provides an interactive order form. The website is built using **HTML5, CSS3, and JavaScript** to provide a simple and user-friendly experience.

- **HTML5** – Used to create the structure of the website.
- **CSS3** – Used for styling, layouts, colors, and overall design.
- **JavaScript** – Used to add interactive features and functionality.

## ✨ Features

### 1. Navigation Bar
- Provides links to the About, Products, and Contact Us sections.
- Includes a Light Toggle button to change the website's theme.

### 2. About Section
- Displays information about ChowChowCrochet.
- Includes a Read More / Read Less button to show or hide additional information.

### 3. Product Cards
- Displays popular crochet products with images, descriptions, and prices.
- Includes an Order Now link for each product.

### 4. Product Categories
- Displays products in a table.
- Allows users to filter products by category:
  - All
  - Bags
  - Hair Accessories
  - Clothing
- Includes a hover effect on table rows.

### 5. Order Form
- Collects the user's name and email address.
- Includes options for placing an order, asking a question, or requesting a custom design.
- Allows users to select multiple products.
- Automatically calculates the total price of selected items.
- Displays age-based discount messages according to the user's birth year.
- Includes a special notes field with a remaining character counter.
- Displays a thank-you message after form submission.

### 6. Additional Features
- Displays the shop's opening and closing status according to the current time.
- Provides links to social media platforms, including YouTube.
